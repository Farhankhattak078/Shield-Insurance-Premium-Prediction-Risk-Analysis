This project analyzes competitor insurance data to help Shield Insurance expand into a new market.

The goal is to build accurate machine learning models for predicting insurance premiums and to understand how lifestyle factors impact pricing.

Objectives
Load and analyze premiums_with_life_style.xlsx
Perform data cleaning and exploratory data analysis (EDA)
Engineer a Life Style Risk Score
Train multiple regression models
Compare performance and select the best model
Analyze high-margin prediction errors (>10%)

Exploratory Data Analysis (EDA)
Handled missing values and data inconsistencies
Analyzed distributions of key variables
Checked correlations between features and premium
Visualized trends using plots


Models Implemented
Linear Regression
Decision Tree Regressor
Random Forest Regressor
XGB Regressor

Model Evaluation Metrics
R² Score
Mean Absolute Error (MAE)
Mean Squared Error (MSE)

Best Model: XGB Regressor

Accuracy rate ; 99%
